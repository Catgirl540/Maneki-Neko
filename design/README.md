# 设计目录用途

当前网页视觉与页面实现的入口在 [docs/design/README.md](../docs/design/README.md)。旧 `brand/`、`shots/` 已移入 [网页归档](../archive/2026-10-15/web-before-redesign/README.md)。

本目录保留运维交接、代码审查、工作人员端资料及历史 Logo 评审服务。`logo-review/` 中的候选和“当前线上版本”名称属于当时评审记录，不代表现在采用的网页标志；服务文件保留原路径以兼容既有配置。

开始修改客户端前先看 [CLIENTS.md](../CLIENTS.md)。
