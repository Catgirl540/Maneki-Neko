## 没有银行卡怎么申请新卡？ {#apply}

进入「账户 → 银行卡 → 申请新卡」，选择产品并填写寄送地址，核对制卡与寄送费用，验证支付密码后提交。费用按所选产品展示，余额不足会失败。新卡初始处于寄送中，线上及境外支付关闭；不承诺固定送达天数。也可请助手查询卡产品并申请，提供完整寄送地址后在确认卡核对产品、扣费账户和费用，验证支付密码。助手不会猜测地址。

## 每位客户能办几张卡？为什么申请被拒？ {#quota}

每位客户至多持有一张 Visa 卡和一张银联卡，两卡共享同一资金账户，可以不持卡、只持一种或各持一张。使用中、锁定、寄送中的卡都占用对应卡组织的名额；锁卡不释放名额。同组织已有卡时不能再次申请，会被拒绝且不收费；如需新卡应办理换卡。产品列表会把已占名额的产品标注为已持有同组织卡。历史已换发的卡保留在卡片列表中，不占名额。

## 会员等级会影响制卡费和汇率吗？ {#member}

会。会员等级按**上月日均 AUM** 评定（普通 / 金卡 / 白金 / 钻石，门槛 ¥0 / ¥10 万 / ¥50 万 / ¥300 万；AUM = 储蓄 + 理财持仓 + 现金管理，不含授信），在「安全设置 → 会员中心」查看。制卡/换卡费按等级有年度减免次数（金卡半价一次、白金全免一次、钻石全免两次且含寄送费），申请页会直接显示减免后的实付金额；换汇点差按等级打折（金卡九折、白金八折、钻石七折）。金卡起境外转账手续费全免、客服工单 VIP 优先；白金起有专属客户经理、理财优先购和贵宾厅 2 次/年；钻石另有专属理财顾问、贵宾厅 6 次/年和境外汇款手续费减免。升级即时生效，降级需连续 2 个评定周期未达标。会员升级不新建账户、不改账户号、不改余额与流水。

## 卡丢了怎么锁卡、解锁或挂失？需要支付密码吗？ {#lost}

立即进入「账户 → 银行卡」选择该卡，可先锁卡拦截消费，再选择正式挂失并验证支付密码。正式挂失是独立 lost 状态，普通解锁不能解除；找回后验证支付密码解挂，只恢复挂失前状态，支付开关保持关闭。待激活卡即使挂失后找回仍须单独验密激活。也可选择挂失补卡，旧卡失效，新卡仍待激活。锁卡、挂失都不释放卡组织名额，不等于冻结整个资金账户，也不阻断资金账户转账。普通锁卡/解锁无需支付密码，且仅限已激活或锁定卡。

## 换卡怎么操作？旧卡还能用吗？ {#replace}

在「账户 → 银行卡」选择换卡，核对地址与费用并验证支付密码。旧卡变为已换卡，新卡使用新的卡号与安全码且为寄送中状态。已换发的旧卡不能再次换卡或锁卡。费用以页面产品与确认结果为准，助手也可办理换卡，需要明确旧卡和完整寄送地址，在确认卡核对费用并验证支付密码。

## 怎么设置线上支付、境外支付与银行卡日限额？ {#settings}

在「账户 → 银行卡」选择卡片管理支付开关和日限额。已锁卡时不能直接打开线上或境外支付，需先解锁；解锁后应重新检查开关。新申请卡当前初始日限额为两千元，其他卡以实际设置为准。助手可在确认卡核对后修改线上、境外支付开关及日限额，无需支付密码。当前助手日限额选项为两千、五千、一万或五万元；寄送中或已换发旧卡不能通过助手修改设置。

## 如何查看完整卡号和 CVV 安全码？ {#secrets}

在银行卡页发起查看并验证支付密码。助手也可发起查看卡号或 CVV，验证后仅在临时安全弹窗显示；助手不会收到完整敏感值，不应把密码或安全码发到聊天正文。寄送中和已换发旧卡不可查看；当前临时显示六十秒，以弹窗倒计时为准。

## 模拟消费是什么？会真的扣钱吗？ {#spend}

服务菜单「账户与支付」分组里的「模拟消费」是演示刷卡：选择本人使用中的卡、12 个预设商户之一或自定义、Stripe 两个自由收单入口，填写金额与可选账单详情后提交。它只在本行演示环境可用，不接真实收单、不产生真实商户扣款，扣的是该卡所属资金账户的演示余额，因此也不会产生真实退款或商户对账。单笔上限 ¥50,000.00，账单详情最多 80 字单行；自由商家需填 2–40 字商户名。卡处于锁定、寄送中或已换发状态，或关闭了消费、线上支付时不能消费；单卡单日限额按当日已成功消费累计。消费会写入卡渠道流水，分类由后台任务异步完成，页面上会先显示「正在分类」，返回的 `other` 不是最终分类。助手可用 `bank_spend` 办理，核对卡、商户与金额后确认即可，不需要支付密码；不支持退款、撤销、分期或修改已生成流水。
