# 网页助手功能维护

## 当前能力

生产 HTTP 模式共 24 个银行工具，沿用当前登录客户的银行接口。

| 功能 | 工具 | 提交要求 |
|---|---|---|
| 余额、流水、交易详情、理财产品 | 原有查询工具 | 确认 |
| 银行及 FPS 转账、理财申赎、卡安全信息 | 原有办理工具 | 确认及支付密码；申购需本人抄录风险确认 |
| 卡列表、卡产品 | `bank_list_cards`、`bank_card_products` | 确认 |
| 锁卡、解锁、支付开关、日限额 | `bank_set_card_lock`、`bank_update_card_settings` | 确认，无需支付密码 |
| 申请新卡、换卡 | `bank_apply_card`、`bank_replace_card` | 完整寄送地址，确认实际费用及扣费账户，支付密码 |
| 已有自动扣款查询、启停 | `bank_list_autodebits`、`bank_set_autodebit` | 确认，无需支付密码 |
| 月度消费、现金流 | `bank_get_spending`、`bank_get_cashflow` | 确认，使用银行全量统计 |

寄送中卡片不能通过助手解锁或修改设置，已换发旧卡不能重复办理。卡日限额采用网页的四个选项；自动扣款只管理已有签约。确认后若卡状态、设置、扣款签约或费用已变化，需重新确认。

## 转账与收款人

新增银行名录、已存收款人、FPS 登记及收款账号校验查询。银行代码与地区成对使用；非账号 FPS 仅使用登记解析的默认银行，不补猜掩码姓名。跨币种金额按付款币种计，确认卡展示实际手续费、汇率、收款金额及报价截止。

银行服务公布报价校验版本，旧版本不允许助手提交。桥接提交前重新核对报价和 FPS 登记，银行在扣款或冻结的同一串行区间再次校验。换汇报价三十秒有效，确认到期自动失效；已受理在途指令保留价格条件，结算时条件变化则失败并解冻。撤回只限冻结窗口内的在途转账，确认后执行，无需支付密码；普通外行清算不能撤回。

## 停止生成

输入区在生成期间显示停止按钮。网页调用当前会话的停止接口，服务端通过私有 Unix socket 调用运行时公开的 `Agent.cancel`，不关闭共享运行时。socket 在独立临时目录中，权限为 0600，并校验内部随机令牌。

停止后保留已显示正文，取消未执行的授权及待答问题，等本轮空闲后再发送。已经提交银行的操作不能靠停止生成撤回，结果需查询银行记录。活动标记会拦住取消后迟到的授权准备及提交。

## 工具可用性

银行工具注册、生产允许列表与自检允许列表必须一致。构建及 bootstrap 调用 `check-bank-tool-policy.mjs` 校验，HTTP 桥接启动时再次检查实际 profile；漏配时启动失败，避免出现界面宣称支持但运行时拒绝的情况。允许列表仅显式增加已注册的业务功能，不放开命令执行或文件访问。

## 重启恢复

服务端将会话归属与最近 256 个可重放事件保存在 SQLite 索引，完整上下文仍使用 Harness 原生会话日志及附件。SDK 适配层只通过公开的 `agents.create/resume` 恢复命名会话，沿用官方协议服务，不修改依赖代码。原生日志保留用户、助手、工具结果及压缩记录，恢复后更新当前提示与工具能力。

`LUCKYCAT_SESSION_DIR` 默认指向框架 `.dsh-home`；发布必须保留其中的 `web-context/`、`sessions/` 和附件目录。索引文件权限 0600，不保存银行令牌、支付密码、一次性授权或卡密。登录后先核对持久化归属，再以本次登录令牌查询银行。

重启不自动继续旧指令。崩溃前未完成的工具由原生日志补上中断标记，旧确认及问题作废，待处理输入清空；已提交银行的业务须重新查询实际结果。旧版本未保存可信归属，不能凭旧会话 ID 认领；网页自动将最近 40 条、最多 48 KB 的本机文字迁入新会话，仅作客户提供的参考，不作为银行回执或授权，原图需重发。

`tools/check-agent-restart.mjs` 使用本地模型和临时银行，验证正常及强制重启、完整上下文和图片、多客户隔离、游标续取、确认失效、部分正文及旧记录迁移。

## 验证

使用 Node 24。`tools/check-agent-tool-access.mjs` 以本地模型协议、真实 Harness 和临时 SQLite 银行验证模型侧工具清单与完整申请新卡流程，不发送外部模型请求。`tools/check-agent-bank.mjs` 在临时 SQLite 银行中验证账户隔离、实际状态与扣费、确认绑定、取消与重放。`tools/check-agent-streaming.mjs` 使用本地模型协议和浏览器验证流式、停止、继续发送、并发隔离、确认及提问等待中的取消。`tools/check-agent-transfers.mjs` 随银行集成测试验证四种 FPS、跨币种实扣、报价条件与在途撤回；`tools/check-transfer-quotes.mjs` 在内存中验证在途结算价格变化与撤回截止。`tools/check-agent-polling.mjs` 验证登录、停止接口归属、游标、短请求降级与敏感事件。

业务或能力有变动时，同步更新 `framework/knowledge/` 与对应断言，再生成语料。
