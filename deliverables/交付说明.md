## 五、生成方式（可重跑）

```bash
# 图表（架构图、部署图、流程图、安全图、封面横幅）
python deliverables/build_figures.py

# 技术文档（内容在 doc_content_a.py / doc_content_b.py）
python deliverables/build_docx.py
python deliverables/check_docx.py     # 残留标记检查
python deliverables/verify_docx.py    # 表格宽度 / 图片宽度 / 代码行宽检查

# 答辩 PPT（PowerPoint 渲染校验需要本机 PowerPoint）
python deliverables/build_pptx.py
```

本机环境说明：Office 的 Word 自动化被运行环境阻断（COM 无法挂载），因此技术文档未附 PDF；PPT 已用 PowerPoint 原生渲染逐页核对（`预览/` 即其输出）。
