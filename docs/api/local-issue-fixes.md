7. 定投校验扣款账户归属、理财开户、有效风险测评、适当性、周期和密码，并保存账户ID。周期任务执行仍属原规划范围。

## #9 的修改

### FPS

- 收款资料明确返回 `fpsRegistered` 和登记集合；未登记返回空手机号/ID。登录手机号不自动成为FPS标识。
- `POST /api/receiving/fps` 登记请求：`idType`（mobile/email/fpsid）、`id`、`accountId`、`region: HK`、`currency: HKD`、`paymentPassword`。
- 校验当前客户账户归属、港币币种、格式和全局标识唯一性；登记随客户档案持久化。
- 解析、收款展示和执行使用同一登记源。本地登记转账执行双方扣入账和流水；未登记拒绝。
- 本行 `LCB/HK` 是明确标注的香港港币**模拟通道**，没有接入真实FPS网络。支持本地登记的付款账户与收款账户均为港币；原外行登记夹具保留。
- 登记后的展示及复制恢复；旧后端未提供登记状态时继续显示待确认。

### 登录审计

- 银行HTTP鉴权层新增持久化会话历史和审计表，记录登录成功/失败、退出、过期、服务重启失效。
- `GET /api/security/overview` 返回真实会话历史、`active/current`及`sessionAuditSupported`。界面区分已失效会话。
- 客户日志仅按客户ID查询；未知账号失败写入服务端审计，不向其他客户分配记录。
- 会话令牌仍只在内存；重启将历史会话标记失效。持久化会话标识为摘要，设备信息只保存浏览器类别，位置为未知，不存密码/验证码/Bearer或原始请求头。

### 测试阈值与风险语义

- Agent临时测试服务明确设置 `BANK_TRANSFER_REVIEW_CENTS=500000`，不修改生产默认50万元阈值。
- 补齐阈值下方/恰好/上方、热修改、冻结/撤销/拦截、失败解冻及跨客户自动到账回归。
- 风险接口区分 `unassessed/expired/valid` 与 `eligible`。未完成测评返回空等级和分数、空日期、`expired=false`；购买和开户仍检查完成状态、有效性及适当性。
