# 网页工作台改版记录

## 依据与范围

使用用户导出的 `exports/2026-10-15/zhaocai-cat-bank.html`，实施桌面网页客户端。用户已取消双模式；移动端交由 App。本次未改银行接口、Agent 协议或公网部署。

## 页面结构

- 首页 `/dashboard` 与兼容地址 `/support`：智能工作台、十个任务入口、持续会话、历史、转人工。
- 侧栏保留转账、银行卡、账单、理财；资金余额在 `/accounts`，完整服务目录在 `/services`。
- 业务页面底部使用同一助手输入栏，发送时带任务类别回到首页。助手组件跨页面保活，保留文字草稿、待发图片、流式连接与待确认事项。
- 转账页复用现有 TransferForm；资金页仍提供原有转入/转出弹窗。旧 flow 地址兼容。
- 品牌使用导出稿资源；客服形象使用 `mascot/support-cat-v1.png` 的原始图像，首页、消息与思考状态共用。
- 银行卡上方展示当前卡，下方堆叠其他卡；选卡平滑移到展示位，原卡回到卡堆，右侧同步显示关联账户与交易设置。卡面统一尺寸，寄送信息独立弹窗；减少动态效果设置下直接切换。
