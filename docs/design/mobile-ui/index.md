# 移动端 UI 树

依据：`../drafts/2026-10-20-mobile-framework.html`（静态原型）。
每个节点一张截图 + 指向子节点的指针。**页面改动时同步更新本树**（重跑截图脚本并修订结构）。
实现 Flutter 时按本树搭建导航栈，不要读 HTML 源码。

约定：

- `tab` = 底栏一级页（底栏常驻）；`push` = 推入的二级页（隐藏底栏、顶部返回）；`sheet` = 底部弹层。
- 按钮统一近黑 `#101826`，紫色 `#533afd` 只用于选中 tab 与少量点缀。
- 占位节点（子页仅有返回栏与页名）后续填内容。
- 截图体现不出的动效/交互，在各节点「备注」里注明。

## 通用动效与行为

| 位置 | 行为 |
| --- | --- |
| 页面切换 | 瞬时切换，无滑动/淡入过场（`display` 直接切换） |
| 底栏四个线图标 | 点击触发**描边动画**：各 path 依次画出，460ms/段、段间隔 140ms、cubic-bezier(.4,0,.2,1)；选中图标变紫 |
| 中间猫钮 | 点击触发**探身动画**：猫上移 6px + 左倾 7° → 回摆 3° → 归位；圆钮同步 scale 1.07；均为 520ms cubic-bezier(.22,1,.36,1)。**延迟 300ms 后推入助手页**（动画未播完就切页，比原来快） |
| 底部弹层 | sheet 上滑 280ms cubic-bezier(.4,0,.2,1)，遮罩淡入 220ms rgba(6,27,49,.32)；点遮罩或内部关闭逻辑收起；跳页前自动关所有弹层 |
| 右侧抽屉 | drawer 右滑入 280ms 同曲线，宽 80%，与弹层共享遮罩与关闭逻辑 |
| 分段选择 seg | 点击切换，选中项白底加粗，track 浅灰；无滑动指示器 |
| 静态元素 | 眼睛/复制/麦克风/发送/搜索框等图标仅示意，原型无真实行为 |
