## 三个核心比赛场景

| 场景 | 可走的实际链路 | 明确边界 |
| --- | --- | --- |
| 智能转账 | 查询本人账户/收款信息 → 补参数 → 确认验密 → 回执/余额/流水；本人在途确认撤回 | 定时转账、AA 尚未实现；处理中不等于到账，撤回不是退款 |
| 理财操作 | 实际产品目录 → 产品对比/风险与费用 → 本人适当性 → 申购抄录风险语句/验密或赎回；定投计划管理 | 不代答测评、不排序代客决策、不保证收益；定投不自动执行 |
| 卡片管理 | 本人卡片/产品查询 → 锁卡、支付开关/限额、申请或换发 → 实际状态 | 单资金账户，每组织至多一张占用名额；卡密临时显示，不进模型/历史；锁卡不等于正式挂失 |

账单与订阅还补充了真实月度统计、续费清单和有限样本核查。异常候选不等于欺诈，续费清单不是后台提醒，停用本行代扣不等于取消商户订阅。上述是实现与本地证据核对，不是正式比赛评分。
