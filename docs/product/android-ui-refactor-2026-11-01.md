## 验收方法

- 构建：`:app:assembleDebug :app:assembleDebugAndroidTest :app:assembleRelease :app:lintDebug --offline`，JDK 21、Gradle 8.14。
- 静态门禁：`npm --prefix app run check:account-model`、`node tools/check-android-catalog.mjs`。
- 功能与交互：`MANEKI_ADB=/data/sdk/Android/Sdk/platform-tools/adb node tools/check-android-parity.mjs emulator-5554`，复用一次性本地 PostgreSQL 夹具，最终对账；没有使用线上账户执行测试。
- 新增交互断言：预算概览不暴露字段、进入二级表单可输入、关闭再进入保留草稿；定投、现金规则、生日、模拟消费、定时与 AA 的入口可达；转账确认只核对、不输入密码或提交，并断言不重复展示完整收款账号；真实底栏能进入我的和银行卡。
- 恢复回归：`FinancialRecoveryTest` 覆盖持久化、并发、报价核对、分摊、严格日期、FPS、CSV 和响应完整性。
- 视觉证据：`docs/design/mobile-ui/screens/2026-11-01-refactor/`，由测试模拟器重拍，覆盖概览、二级表单与真实导航。

## 范围说明

本轮不改变银行 API、账户归属、金额记账、风险测评、金融授权或恢复协议。输入草稿不包含支付密码，密码仍只保留在原有临时状态并在结束时清空。修复了 `BigInteger.longValueExact()` 在 minSdk 26 上的兼容性问题，改用原值的 `BigDecimal.longValueExact()`，仍拒绝非整数分或溢出。

保留既有外部通道限制：真实银行清算、微信投递、真实短信及活体检测并未在本轮开放；通知偏好与英文界面不虚构保存成功。IM 本地夹具未实现助手接口，截图中的不可用状态用于验证降级布局，不代表线上绑定已验证。

安装包在 `android-app/app/build/outputs/apk/release/app-release.apk`，版本 `1.0.7 (8)`。本轮只构建交付，未上传官网或发布自动更新。
