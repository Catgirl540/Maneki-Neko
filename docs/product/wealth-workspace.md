# 网页理财中心

虚构产品、费率、基准与执行简化见 [理财产品目录](wealth-products.md)，普通申赎契约见 [理财接口](../api/wealth.md)。

本次只整合网页用户端 `app/`，沿用现有蓝紫色工作台和银行接口；不修改工作人员端、不恢复双模式。

## 页面分工

- 理财总览 `/wealth`：持仓市值、投入本金、昨日与累计盈亏，持仓摘要和开户/测评/封闭期即将结束事项。产品无需开户即可浏览。统计采用理财概览的 CNY 口径，不把储蓄、存钱目标、计划金额或历史现金管理余额重复加总。
- 理财产品 `/wealth/products`：分类、关键词、风险、开放条件和起购金额筛选；有效测评才能使用“仅看风险匹配”。支持两款产品比较风险、期限、起购/递增、基准依据与费用；比较不扣款、不申购。现金管理纳入统一目录，旧活钱规则从现金管理分类进入二级设置 `/wealth/cash-management`。
- 我的持仓 `/wealth/holdings`：全部、可赎回、封闭期分类；查看份额、市值、盈亏和确认日期，复用现有赎回窗口。封闭期依据服务端 `closed` 禁用赎回；产品目录查询失败不能凭空补产品、净值或启用赎回。
- 储蓄与计划 `/wealth/plans`：存钱目标；`?tab=invest` 为定投计划，复用已有管理表单。计划只保存规则，自动执行尚未开放；目标不代表独立资金账户，不将目标金额算成投资资产。
- 交易记录 `/wealth/records`：切换申购/赎回相关资金流水，服务端分页；保留类型、页码，详情和回单复用 `/transactions/:id`。当前没有独立理财订单接口，只能展示资金记账状态，不能假造待确认订单、份额进度或到账阶段。

保险保障独立放在「个人与安全」，保留原 `/wealth/insurance`。

## 业务边界

一个储蓄资金账户，多币种余额。理财开通仅建立投资资格及委托关系；继续复用实名资料，以测评、短信、人脸和投资协议完成前置流程；申赎通过原资金账户结算。风险、收益与费用披露、支付密码、本人抄录及服务器适当性检查保留。申购金额需本人聚焦输入后编辑，避免浏览器把登录名自动填入金额；风险确认使用独立文本域，不代填。必要字段未齐全时不能提交，提交过程中不能关闭申赎窗口。定投创建前复用共享适当性校验，缺少开户/有效测评或风险不符时提前提示。

资产与持仓金额默认遮罩。数据失败显示重试入口，不把失败或缺失当成 0；产品源失败单独提示，不阻断已获得的概览。收益仅取当前环境的概览或产品接口返回；演示环境中的返回不代表真实业绩，产品比较无收益排序、保本或未来收益承诺。

赎回回执与账务当前存在口径差异：回执写预计 T+1，演示实现会即时记账。网页只展示两者各自事实，不新增定时到账假象；若后续建设真正的委托订单与清算能力，需同一提交同步接口、页面、知识/技能和断言。

## 兼容和维护

旧 `/dashboard/savings` 跳转到 `/wealth/plans`，旧 `/wealth/investments` 跳转到 `/wealth/plans?tab=invest`。新侧栏与全部服务共用 `WEALTH_ROUTES`，避免同一个功能出现多套入口；现金管理设置归属产品，助手路径映射覆盖五页。

核心文件：`pages/WealthPage.tsx`、`WealthPlansPage.tsx`、`WealthRecordsPage.tsx`；公用头部与样式在 `components/wealth/`。筛选、持仓分类、资金流水查询条件与入口清单在 `lib/wealth-workspace.ts`。

验证：`npm --prefix app run build`、`npm --prefix app run check:account-model`、`node --import ./tools/ts-resolve-hook.mjs ./tools/check-wealth-workspace.mjs`、知识语料和技能校验。浏览器验证：未开通浏览、产品筛选/清空/两款比较、风险不匹配禁止申购、持仓遮罩/封闭期、计划旧链跳转、流水分页与详情返回。资金写回归使用可丢弃数据，不操作真实客户资金。

## 浏览器验收夹具

运行 `node --import ./tools/ts-resolve-hook.mjs ./tools/wealth-ui-fixture.mjs` 在本机 `127.0.0.1:5185` 启动独立预览。它在隔离内存中准备开放持仓、封闭持仓和 14 条申购流水；第二页首次请求故意失败，重试后恢复，便于检查重试和旧页缓存。演示登录可填任意 11 位手机号、非空密码和短信 `123456`。所有银行业务写接口拒绝，银行及 Agent 未提供的接口直接报错，不代理到真实银行、客户库或模型。按 Ctrl+C 退出，不作为部署服务。

本轮浏览器已核验：真实本地新客户的空态、产品搜索与组合筛选、两款比较、详情费用标签、计划类型/助手能力切换、旧路由跳转；隔离夹具核验开放/封闭持仓、申购表单必填保护、流水失败重试及详情返回第二页。业务写入闭环通过 `check-wealth-workspace.mjs` 的隔离内存 API 完成，未对正在使用的客户数据执行申赎。
