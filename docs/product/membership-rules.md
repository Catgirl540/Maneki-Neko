# 招财猫银行 · 会员制规则设计

> 版本 v1.0（纯资产分层，对标中国真实银行） · 2026-10-20 · 状态：已定稿
> 决策：**砍掉付费订阅**，只做「资产达标送权益」的会员分层——贴合中国零售银行现状（招行金葵花 / 工行星级）。

---

## 0. 现状与问题

当前仓库会员相关代码有三处问题：

1. **「会员等级」与「付费订阅」割裂且矛盾**：`User.memberLevel`（硬编码字符串，显示在侧栏/安全中心）与 `MembershipSubscription`（付费订阅，显示在会员页）是两套东西。种子数据里林小满侧栏 =「金卡会员」，但会员页 =「普通会员 / none」。
2. **权益纯文案**：套餐 `perks` 只是字符串数组，没有任何业务逻辑真正消费。
3. **付费订阅本身方向有偏差**：中国零售银行受「减费让利」监管 + 用户免费化习惯，几乎不做付费订阅，主流是**资产达标送权益**。

> 因此本版**删除付费订阅**，统一为纯资产分层。

---

## 1. 真实银行怎么做（调研结论）

### 1.1 分层门槛（一律按 AUM 金融资产）

| 银行 | 入门 / 金卡 | 贵宾 / 财富 | 私人银行 |
|---|---|---|---|
| 招商银行 | 一卡通金卡 5 万 | 金葵花 50 万 | 1000 万 |
| 工商银行 | 五星级 20 万 | 六星级 100 万 | 七星级 600 万 / 私银 800 万 |
| 华夏银行 | 金卡 20–60 万 | — | — |
| 交通银行 | — | 沃德 50 万（季日均） | — |

**共性**：按**金融资产 AUM**（存款 + 理财 + 基金 + 国债等，非单纯存款）、按**月 / 季日均**评定、**动态管理**（资产不达标则降级）。

### 1.2 权益体系四层结构

「**费用减免为底座、出行为亮点、专属服务为核心、增值为补充**」：

- **底座 · 费用减免**：转账 / 异地 / 跨境手续费减免。
- **亮点 · 出行**：机场 / 高铁贵宾厅（邮储鼎致白金 6 次/年、招行云聚英才 2 次/年）。
- **核心 · 专属服务**：专属客户经理（一对一）、贵宾专线、VIP 通道 / 优先排队。
- **补充 · 增值**：专属理财（优先购）、生日礼、健康医疗。

---

## 2. 总则：资产达标送权益

- 会员 = **会员等级**（客户分层），按**月均总资产 AUM** 自动评定，**免费**。
- 等级决定**全部权益**，人人依资产可得，无需付费订阅。
- 权益随等级**递进**：高等级含低等级全部权益。

## 3. 会员等级与门槛

| 等级 | 月均总资产（AUM）门槛 | 参考对标 |
|---|---|---|
| 普通会员 standard | < ¥10 万 | 大众客群 |
| 金卡会员 gold | ¥10 万 ~ ¥50 万 | 招行一卡通金卡(5万) / 工行五星(20万) |
| 白金会员 platinum | ¥50 万 ~ ¥300 万 | 招行金葵花(50万) / 工行六星(100万) |

## 4. 等级权益（递进式）

| 等级 | 权益 |
|---|---|
| 普通 | 基础银行服务 |
| 金卡 | 转账手续费减免 · 网点 / 客服 VIP 通道 · 生日礼遇（暂缓） |
| 白金 | 含金卡 + 专属客户经理 · 专属理财优先购 · 机场 / 高铁贵宾厅 2 次/年 |
| 钻石 | 含白金 + 专属理财顾问 · 机场 / 高铁贵宾厅 6 次/年 · 境外汇款手续费减免 |

---

## 5. 权益落地方式（核心：真生效）

每个权益对应一个**明确的业务生效点**，不是文案。

| 权益 | 门槛 | 业务生效点 | 落地机制 |
|---|---|---|---|
| 转账手续费减免 | 金卡+ | 转账报价 `transfers/quote` + 执行 `submitTransfer` | 手续费系数 ×0 |
| VIP 通道 / 客服优先 | 金卡+ | 客服工单排序 | 工单优先级提高 |
| 生日礼遇 | 金卡+ | 会员页 / 消息 | 生日月发放礼物 / 券 |
| 专属客户经理 | 白金+ | 助手 / 客服入口 | 对话挂「专属通道」标识、优先路由 |
| 专属理财优先购 | 白金+ | 理财产品申购 `subscribeWealth` | 热门产品对高等级开放**提前申购窗口** |
| 机场 / 高铁贵宾厅 | 白金(2次) 钻石(6次) | 权益券核销 | 年度 N 次额度、核销计数、年末清零 |
| 专属理财顾问 | 钻石 | 助手 / 客服入口 | 钻石等级专属顾问标识 |
| 境外汇款手续费减免 | 钻石 | 跨境汇款费率计算 | 手续费系数 ×0 |

> **落地原则**：权益判定收敛为一个 `entitlements(tier)` 函数，返回当前等级权益集合；各业务函数在收费 / 排队 / 核销处统一调用它，而不是各自散写 if-else。

## 6. 评定规则（升级 / 降级）

- **AUM 口径**：所有储蓄账户 + 理财持仓 + 现金管理的**月末时点资产合计**（含活期 / 定期 / 理财，不含信用卡额度）。
- **评定周期**：每月 1 号按上月日均资产重算。
- **升级**：资产达标的**当天**即时升级（不等月底）。
- **降级**：连续 **2 个评定周期**不达标才降（1 个月缓冲，避免资产波动频繁跳档）。
- **升级进度**：会员页展示「距下一等级还差 ¥X」进度条（如白金 → 钻石还差 ¥172 万）。

## 7. 数据模型

### 7.1 现状调整

- `User.memberLevel: string`（`types.ts:18`）→ 改为枚举 `MemberTier`，由 AUM 派生，**不再硬编码字符串**。
- **删除** `MembershipPlan` / `MembershipSubscription` 类型，及 `subscribeMembership` / `cancelMembership` 两个接口。
- **删除** `MockDb.membership` 里的订阅字段（`current` / `plans` / `records`），改为等级相关字段。

### 7.2 目标类型

```ts
type MemberTier = 'standard' | 'gold' | 'platinum' | 'diamond'

// User 上：memberLevel: string → memberTier: MemberTier（由 AUM 派生）

// 会员概览（替代原 MembershipOverview）
interface MembershipOverview {
  tier: MemberTier
  tierLabel: string          // 「白金会员」
  aum: Cents                 // 当前月均资产
  nextTier: MemberTier | null
  nextThreshold: Cents | null // 距下一等级的资产门槛
  benefits: string[]         // 当前等级权益文案（展示用）
}

// 权益集合：由 entitlements(tier) 返回，业务函数消费
interface Entitlements {
  freeTransferFee: boolean
  vipChannel: boolean
  birthdayGift: boolean
  dedicatedManager: boolean
  wealthPriority: boolean
  loungePasses: number       // 机场/高铁贵宾厅年度剩余次数
  freeOverseasRemit: boolean
}
```
