# 银行卡与会员体系

日期：2026-10-19（2026-10 实现版）。卡数量限制与统一会员等级均已实现，本文转为现行规则的维护依据。

卡数量限制与「统一客户会员等级、按上月日均储蓄资产评定」的分级方式已经用户确认并落地。落地口径：评级资产只含资金账户折人民币余额（不含理财持仓）；已接通权益为制卡/换卡费年度减免与换汇点差折扣；旧月费套餐只读保留在 `legacy`，停止办理。

## 1. 已确定的数量与建议落地口径

每位客户继续只有一个储蓄资金账户，Visa、银联卡各至多一张，两种卡共享该账户的多币种余额。两种卡均为借记卡，不因卡组织或会员等级产生授信。

- 可以不持卡、只持一种卡，或各持一张；开户不强制同时办两张卡。
- 制卡中、寄送中、待激活、使用中、锁定的卡均占用对应卡组织的名额，锁卡不能释放名额。
- 同组织已有卡时引导管理或换卡，禁止再次申请并收费。
- 换卡在同一笔原子操作中使旧卡失效、新卡接替名额；失败不扣费、不作废旧卡。历史卡保留，不能作为可支付卡使用。
- 实体卡和独立虚拟卡共用同组织名额。已有卡的支付令牌、受控一次性卡号属于该卡的凭证，不形成独立资金账户或额外持卡名额。
- 新卡、换卡和会员升级均不创建资金账户，不修改账户号，不改变余额或已有流水。

## 2. 分级方式（已确认并实现）

统一客户会员等级，Visa、银联共享等级与权益。卡组织负责支付网络，会员等级负责客户权益；不为每个等级再建立一种银行卡产品。

四档：白银、黄金、铂金、钻石。会员由资产达标获得；按月购买金卡、白金套餐的旧设计已移除，旧订阅记录收进 `legacy` 只读保留，不再扣费。

门槛：白银开户即享，黄金上月日均资产满 1 万元，铂金满 10 万元，钻石满 50 万元。以上是本项目的确认参数，不是 ZA 或微众的现行门槛。

评定：按北京时间每日末快照统计，上月日均资产决定本月等级；当月新客从白银开始。界面展示统计区间、下次评定日期和升级差额，不把当前余额直接当作月日均资产。缺少历史快照的日子按 0 计入日均，不编造历史达标情况。评定惰性触发：读取会员页、申卡、换汇等入口在跨月时自动完成本月评定。

评级资产采用资金账户折人民币余额（储蓄），理财持仓、借款额度、未结算入账不计入；外币分区按中间价折算。演示档案的种子快照是初始凭证，正式客户的快照从落库起逐日积累。

## 3. 权益边界（已实现部分）

所有会员均保留转账、银行卡安全管理、电子账单、助手和转人工等基础功能。

已接通结算的权益：制卡/换卡费年度减免（白银无、黄金半价 1 次、铂金全免 1 次、钻石全免 2 次且含寄送费）与换汇点差折扣（黄金 9 折 / 铂金 8 折 / 钻石 7 折）。减免次数按自然年重置，申卡/换卡前由后端计算实付报价（`feeQuote`），成功办理后核销并写入权益使用记录；前端显示等级不等于已经获得减免。

“专属客户经理、机场贵宾厅、旅行险、手续费全免”等文案未接入，不作为权益展示；返现、加息列为规划中（`plannedPerks`），接通前不展示为已享权益。升级不改变风控、风险测评、支付确认或实际转账限额。

## 4. 页面组织（已实现）

申卡弹层列出全部卡产品：已占名额的产品置灰并标注「已持有同组织卡」与换卡提示；实付金额按 `feeQuote` 展示（减免时划去标价）。历史卡保留在卡片列表中，不占名额、不可操作。

“会员与订阅”已改为“会员等级”，展示等级、评定区间与日均资产、升级差额、年度权益用量及评级/使用记录；旧套餐订阅收进「历史订阅记录」只读展示。`user.memberLevel` 与会员等级同源，不再保存互相矛盾的等级文案。

会员升级立即更新数字展示；已寄出的实体卡保持原样。需要新卡面时由用户主动申请同组织换卡，不自动换号、收费或寄卡。

## 5. 实现与迁移

新演示档案已调整为每组织最多一张在用卡（1 张在用 Visa + 2 张 replaced 历史卡：1 银联、1 Visa）。服务器存量重复卡不静默删除或作废：全部保留为 `replaced`/历史记录并阻止继续增发；余额、冻结、流水和历史卡记录全部保留。旧会员订阅收进 `membership.legacy` 只读保留，不触发自动扣费；`normalizeMembership` 对全版本档案幂等修补。

名额强制在服务端 `openCard`（HTTP / mock / Agent 共用同一 domain），校验先于支付密码与收费；HTTP 层请求串行化 + 单元事务保证并发安全，`openCard`/`replaceCard` 走既有幂等键。换卡为单笔原子操作。

## 6. 实施与验收

数量限制由后端按客户和卡组织校验，并覆盖并发、幂等、网页、App 与 Agent 入口；前端禁用重复申请仅用于提示。换卡按同组织处理，重复提交不重复扣费、发卡或消耗权益。

落地时同一提交更新账户模型、银行卡及会员接口说明、知识库、技能和断言；回归现有资金、锁卡、换卡、确认与取消流程。会员需要独立的日终快照、评定记录和权益使用记录，不能只修改前端标签。
