# PostgreSQL 单账户整合草稿

状态：2026-10-17 已完成本轮本地整合与回归，继续保留 PR #12 草稿，等待代码审核。尚未合入 main，也未部署公网。

## 本轮结果

- 保持一个资金账户、多币种余额、多张银行卡。服务端余额变动改为解析币种分区，修复首次换汇报账户不存在。
- live 模式夹具使用不同客户各自的唯一资金账户，继续验证全部兼容金融接口、员工及 Agent 通道拒绝执行模拟业务。
- 新增旧账户迁移、冻结金额、原始交易及凭证身份、重启、重复迁移、旧 ID 写入和旧账号收款回归。
- 验证跨币种 FPS 按登记币种贷记，重复请求不重复扣款；境外转账本金、手续费、收款人簿和幂等响应同事务提交，手续费写入失败时整体回滚。
- 补回员工客户查询所需的脱敏和状态标签函数；员工余额及近期交易分别显示实际币种，不把美元或港币标成人民币。
- 理财申购先校验开户状态，避免未开户时错误提示结算账户不存在；同步浏览器模拟和服务端规则。
- Agent 取消沿现有私有 stdio JSON-RPC 通道调用公开 Agent.cancel，保留内部令牌及客户会话归属校验，移除旧 Unix socket 控制模块。
- 银行 HTTP、员工 Agent 和模型协议检查共用隔离 PostgreSQL 夹具。清理无调用方的旧 SQLite 数据库适配，旧 SQLite 工具保留明确拒绝入口。
- 更新启动指引、账户模型、接口说明、后端维护说明、知识库和业务技能。

## 审核与发布边界
