# 客户 IM 网页功能恢复（2026-10-23）

IM 合并到助手视图后，新的 `ImConnectView` 仅挂载连接状态和扫码组件，提醒与解除绑定的后端接口仍存在，但网页没有入口。本次在现有 `/assistant?view=im` 视图恢复功能，不恢复旧独立页面；`/reminders` 继续兼容跳转。

## 修复范围

- 恢复提醒接收微信、文字、北京时间、核对确认创建、记录和二次确认取消。请求编号保存在确认草稿，失败重试沿用原编号；状态未确认或接收目标变化时不能继续提交旧草稿。
- 恢复每条绑定的解除入口及二次确认；历史连接和失效银行会话也能解除。失败保留弹窗和原记录，成功后刷新连接与提醒接收列表。
- 恢复微信 `#code=` 的自动预填、来源核对和手动绑定；同页更换链接重新核对，旧请求慢返回不能覆盖新来源。`#session=` 保留到原业务确认门户的入口。
- 修正“换绑会替换原绑定”的不实提示。添加/重新连接不会自动解除旧绑定或迁移提醒；每条绑定都能由客户明确解除。
- 扫码任务编号按银行用户隔离，切换账户重置组件草稿；切换助手视图可续扫，已完成回执不作为新扫码任务恢复。
- 后端完成扫码后生成新二维码不再复用旧成功任务；解绑或同一路由重建银行会话后，旧成功回执返回 410。明确的渠道繁忙不消耗二维码次数，真实渠道失败仍计数。
- 请求失败与功能未启用分别展示；“已连接”仅表示银行授权有效，不冒充微信实时在线或提醒送达。
