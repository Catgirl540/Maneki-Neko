## 1. 风格定位

**Quiet Premium Neutral + Swiss rational grid** —— 干净、克制、呼吸感强。
对标 ZA Bank / Monzo / Revolut 的产品气质：**大开大合的留白 + 极少量强调色 + 无阴影的纸感卡片**。

明确排除：渐变紫蓝 / 发光边缘 / 玻璃拟态 / 卡片套卡片 / 假的技术感微标签 / 重投影。

**使用规则**

- 一屏只允许**一个金色主按钮**；金色承担「品牌与主操作」，不承担装饰
- 金色大面积铺底时文字用 `ink`（深墨），不要用白字（对比度不足）
- 金色做正文文字时必须降级到 `gold-deep`
- 蓝金互补只用于**表达对立关系**（收入/支出、线上/线下、当前/其他），不要当纯装饰
- 一屏不超过 3 个色相参与表意

## 3. 字体

- 拉丁与数字：`Inter Variable`（金额加 `tabular-nums`）
- 品牌字标：`Poppins`（几何 grotesk），小写 `luckycat` + 大字距 `BANK`
- 中文：系统字体栈 `PingFang SC / Microsoft YaHei / Noto Sans CJK SC`
- 只加载拉丁子集（约 70KB），中文交给系统字体，这是国内站点常规做法

字号阶梯（桌面）：

| 角色 | 字号 / 行高 / 字重 |
| --- | --- |
| 余额大数字 | 46–64 / 1.0 / 700，tracking -3% |
| 页面标题 | 30 / 1.2 / 700，tracking -2% |
| 侧栏问候 | 19 / 1.35 / 700 |
| 卡片标题 | 17 / 1.4 / 600 |
| 列表主文 | 15 / 1.5 / 500 |
| 正文 / 表单 | 14–15 / 1.6 / 400 |
| 辅助说明 | 12–13 / 1.5 / 400，`ink-mute` |

## 4. 几何与间距

- 圆角：卡片 `24px`，输入框与次级块 `16px`，按钮与 chip 全圆 `999px`，图标底 `12px`
- 描边：统一 `1px solid var(--line)`，**默认不用阴影**（仅浮层与 FAB 用极轻阴影）
- 栅格：侧栏 `252px` 固定 + 主区自适应；主区 `max-w-[1120px]`，`padding: 40px`，间距 `24px`
- 卡片内边距：`28px`
- 侧栏导航项：`48px` 高，`12px` 圆角；active = `gold-deep` 文字 + 金色图标 + **右侧 3px 金色指示条**

## 6. 关键组件

- **主按钮**：高 `48–56px`，全圆，实心 `gold`，文字 `ink`，hover 转 `gold-deep` + 白字
- **次按钮**：白底 + `1px line` 描边，hover 转 `sunk`
- **输入框**：高 `56px`，`16px` 圆角，左侧灰色线性图标，focus 边框转 `gold`
- **涨跌标签**：全圆 chip，正向 `blue-wash/blue`，负向 `coral-wash/coral`
- **交易行**：`64px` 高，`40px` 圆形图标底（收入 `blue-wash`，支出 `gold-tint`），右侧金额 `16px` 600
- **现金流图**：双序列面积图，收入金 `fill-opacity .26`、支出蓝 `.18`，描边 `2.4px` 且 `non-scaling-stroke`
- **环形图**：`24px` 描边、平头端点，按金额降序排序后着色
- **步骤条**：`36px` 圆形序号，当前金色实心，未到浅灰实心
- **浮动客服球**：右下 `56px` 圆形金色

## 7. 签名组件（本 MVP 采用）

1. 无缝 bento 栅格（首页四块核心卡片）
2. 产品 UI 面板堆叠（银行卡面 + 交易设置）
3. 垂直节奏线（流水台账 + 1px 分隔）
4. 双序列现金流面积图

## 8. 动效语气

- 错峰上浮：卡片入场 `opacity 0→1` + `translateY 12px→0`，步进 `60ms`
- 平滑展开：筛选、通知面板高度过渡 `240ms cubic-bezier(.4,0,.2,1)`
- 图表：高度/宽度变化 `500–700ms` 缓动，不做弹跳

## 9. 排版与内容禁忌

- 不用 4 行以上的大标题；hero 标题最多 3 行
- 不用「赋能 / 颠覆 / 无缝 / 下一代」类空话
- 不用无意义的 pill、状态点、假系统标签
- 不在同屏堆叠超过 3 个强调色
- 数字一律等宽（`tabular-nums`），避免跳动

## 10. 交易详情（电子回单）的专属规则

这一页的目标不是"好看"，是**像一张能拿去对账的凭证**，所以它比其它页面更克制：

- **虚线撕口**：凭证头与字段区之间用 `1px dashed line-strong` 分隔，
  这是全站唯一使用虚线的地方，用来把"回单"和普通卡片区分开
- **金额只出现一次大字**：`34px` 700 字重，收入 `blue`、支出 `ink`；
  下方小字只标币种（`记账金额 · 人民币（CNY）`），不重复数字
- **字段列表右对齐**：标签 `13px ink-mute` 左对齐、值 `14px ink` 右对齐，
  行间 `1px line` 发丝线；长数字（交易编号 19 位）用 `break-all` 换行，不省略号截断 ——
  凭证上的号被截断就失去意义了
- **可复制字段带 ⧉**：交易编号与授权码右侧挂一个 `20px` 的复制按钮，
  复制成功走右上角轻提示；打印时该按钮隐藏（`print:hidden`）
- **交易前后余额必须自洽**：右栏固定给出「交易前余额 → 交易金额 → 交易后余额」三段，
  并要求 `前 + 金额 = 后`。这一条由 `tools/check-tx-detail.mjs` 守
- **一屏一个金色主按钮**：这里是「下载电子回单」（演示环境退回打印）；其余全是次级或纯文字按钮
- **打印即回单**：`@media print` 下侧栏、顶栏、浮动客服球、操作按钮、轻提示全部隐藏，
  只留「交易详情」标题 + 凭证本体，圆角与外描边也去掉，直接打印或另存为 PDF
